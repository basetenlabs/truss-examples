# OIDC Recipes
The examples in this folder are recipes for using the OIDC token available to your running model code ([runtime OIDC](https://docs.baseten.co/organization/oidc#use-oidc-at-request-time)).  
As an auth primitve conforming to the OIDC spec, this token is incredible flexible in enabling rich and secure integrations to outside systems. See the subfolders here to get started.
