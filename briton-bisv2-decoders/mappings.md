# Config → Template Mappings (Briton & BISV2 decoders)

Maps every text-generation (`ForCausalLM`) config in `archive/11-embeddings-reranker-classification-tensorrt` to its base template. These are the decoder deployments the embedding `mappings.md` defers here.

Both engines serve causal LLMs via TensorRT-LLM. They map to the two `trt-llm` inference stacks:

- **Briton** = the **v1** stack. `trt-llm.build.base-model: decoder`, no `inference-stack` key. Generated by `llamalike-config()` (and `llamalike-lookahead()` for speculative variants). Supports lookahead speculative decoding and explicit `tensor-parallel-count`.
- **BISV2** = **Baseten Inference Stack v2**. `trt-llm.inference-stack: v2`; build params (`max-seq-len`, `max-batch-size`, `max-num-tokens`) live under `runtime:` and the architecture is auto-detected (no `base-model`). Generated by `llamalike-config-v2()`.

Quantization note: Qwen2-family models cannot use `fp8-kv` (quality issues), so they fall back to plain `fp8` and the generator attaches a larger calibration set (`calib-size: 2048`). FP4 variants (`fp4`, `fp4-kv`, `fp4-mlp-only`) are B200-only.
